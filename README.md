# Aim Trainer

> Transparent overlay desktop app for FPS aim training. Practice while you work.

## Download

[Download for Windows (v2.0.0)](https://jerenai.github.io/desktop-aim/Desktop%20Aim%20Trainer%20Setup%202.0.0.exe)

macOS coming soon.

---

## Quick Start

1. Install and launch — a transparent window floats on your desktop
2. **Click the red dots** to hit them — new dots spawn randomly
3. Drag the window edges to resize freely
4. Watch your stats update in real time at the top

---

## Controls

| Key / Action | Function |
|-------------|----------|
| **Left Click** | Shoot / hit target |
| **W / A / S / D** | Move the canvas (hold for continuous movement) |
| **Drag window edge** | Resize the training area |
| **V** (top-right button) | Open VIP panel (redeem code) |
| **Gear icon** | Open settings |
| **Minus (-)** | Minimize to tray |
| **X** | Close app |

---

## Modes

### Normal Mode (default)
Click targets to hit. Reaction time measured from target spawn to click.

### Hover Mode (VIP only)
Move your cursor over a target — no click needed. Reaction time measured from target spawn to cursor contact. Stats tracked separately from Normal mode.

Toggle in Settings after unlocking VIP.

---

## Stats Bar

| Metric | Description |
|--------|-------------|
| **Hits/min** | Hits in the last 60 seconds (sliding window) |
| **Accuracy** | Hit rate in the last 60 seconds |
| **Total Hits** | Lifetime hit counter |
| **Reaction** | Average reaction time of recent hits |
| **Best** | Best records per difficulty (3+ hits required) |

---

## Reaction Tester

The small circle in the stats bar is a standalone reaction tester:
1. Click the dot → it fades, text: "Waiting..."
2. After a random delay (0.5–7.5s) → dot turns target color, text: "Click!"
3. Click again → shows your reaction time, best, and 10-trial average
4. >1000ms = timeout, resets automatically

## VIP

VIP unlocks:
- **Hover Mode**: cursor touch = hit
- **Permanent ad removal**

Redeem a code via the **V** button in the top-right corner.

---

## Auto Update

The app checks for updates on launch. When a new version is available, an **up arrow** appears in the top-left corner. Click to download and install.

---

## Privacy

- All settings and stats are stored locally on your machine
- No data is sent to any server (except VIP code validation)
- No analytics, no tracking
